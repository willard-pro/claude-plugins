# Skill Reference

The ticket-auto-pipeline ships 25 skills that automate the full Linear ticket lifecycle — from investigation through implementation, verification, and merge. **Pipeline Skills** form the core end-to-end workflow driven by `/ticket-auto`. **Support Skills** provide targeted utilities that can be called independently or are invoked internally by the pipeline.

## Pipeline Skills

| Skill | Purpose |
|-------|---------|
| [ticket-auto](ticket-auto.md) | Fully autonomous orchestrator — drives the entire ticket lifecycle end-to-end |
| [ticket-appraise](ticket-appraise.md) | Investigates a ticket: complexity scoring, prior art, and codebase trace |
| [ticket-appraise-exec](ticket-appraise-exec.md) | Creates the plan artifact and updates Linear after appraisal |
| [ticket-flow](ticket-flow.md) | Centralized executor for all Linear state and label mutations |
| [ticket-implement](ticket-implement.md) | Makes code changes on feature branches and pushes to origin |
| [ticket-pr-iterate](ticket-pr-iterate.md) | Incorporates PR review gaps into the plan for a new implementation round |
| [ticket-pr-review](ticket-pr-review.md) | Validates a PR against ticket requirements and posts a verdict |
| [ticket-retro](ticket-retro.md) | Scans pipeline logs and proposes skill-file fixes for recurring failures |
| [ticket-setup](ticket-setup.md) | Scaffolds the local workspace: directory, context.md, and notes.md |
| [ticket-verify](ticket-verify.md) | Runs Playwright UAT to confirm the fix works in the live app |
