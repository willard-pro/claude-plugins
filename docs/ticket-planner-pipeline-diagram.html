Phase merge: The original 12-phase design separated Proposal, OpenSpec, StoryGen, and Execution as standalone phases. These were merged into Specify (Proposal + OpenSpec) and TicketGen (StoryGen + Execution labelling) — same capabilities, fewer context boundaries. Crosscheck (phase 7) was added later as new deterministic validation, not a merge.
Determinism boundary: Phases 1–6, 10 are LLM agents. Phase 7 (Crosscheck) is deterministic bash with no agent at all. Phase 8 has bash idempotency guards. Phase 9 is bash-gated (DAG, confidence, validation, verification all deterministic). Planned: PLANNER_REVIEW_HOLD and PLANNER_MAX_PHASE_RETRIES are specified but not yet wired into the router dispatch loop. PLANNER_CONSENSUS_HOLD was removed — stopping before the first Linear write (now at Crosscheck) is the default and needs no variable.
